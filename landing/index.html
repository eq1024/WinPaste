Features

Everything you need, nothing you don't.

WinPaste strips away the bloat. Every feature earns its place through daily use.

Zero focus interruption

The panel appears without stealing keyboard focus. Your current work — renaming files, editing cells, typing code — is never disrupted.

Instant search

Hit Ctrl+F or / to focus the search bar. Filter by content, type, or tags. Results update as you type — no delay.

Smart cursor tracking

Uses UIAutomation to detect cursor position even in Chrome, VS Code, and Electron apps where traditional APIs fail. The panel always appears exactly where you need it.

Multi-format capture

Captures plain text, rich HTML, images, file paths, and GIFs. Each entry shows its source application so you know exactly where it came from.

Privacy protection

Auto-detects and masks phone numbers, ID cards, emails, and passwords. Add custom regex rules. Sensitive data is AES-encrypted at rest.

Cloud sync (Beta)

Sync your clipboard across devices using WebDAV. Auto-sync on a schedule with configurable intervals. Full snapshot backups for safety.

Sequential paste mode

Queue up multiple items and paste them one by one with a single hotkey. Perfect for filling forms or copying structured data.

Pin & sticky mode

Pin frequently-used items to the top. Sticky mode lets you detach entries as floating windows that stay visible while you work in other apps.

Fluent Design theme

Dark, light, or system-matched. Windows 11 Mica blur & Windows 10 acrylic. Adjustable font sizes, compact mode, and border toggles.

How it works

Three steps, zero friction.

Copy

Copy anything, anywhere

WinPaste silently records every clipboard change in the background. Text, images, files, code — it all lands in your history with the source app tagged.

Invoke

Press the shortcut

Hit Win+V (or your custom hotkey). The panel appears right at your cursor — even inside Chrome, VS Code, or Excel. Your current app keeps focus. No interruption.

Paste

Select and paste

Navigate with arrow keys, type to search, press Enter to paste. Or use Ctrl+Shift+0-9 to quick-paste your 10 most recent items without opening the panel.

The architecture that makes zero-focus possible.

WinPaste uses a low-level WH_KEYBOARD_LL hook combined with WS_EX_NOACTIVATE window styling — the same technique that powers the system Win+V overlay, but refined to actually work reliably. All hook callbacks are fire-and-forget; heavy lifting is dispatched to async Tokio workers so the input pipeline never stalls.

A Single Source of Truth state machine in Rust eliminates the race conditions that plague clipboard managers — no more stuck modifier keys, no more random keyboard failures after dismissing the panel.
